Reciprocal linking checklist after week two

After ~2 weeks of a capped cadence you usually have four to six live posts in one cluster. That is enough material for sibling links — and also enough rope to hang yourself with a footer farm. This checklist is for founders of small software companies who already ship a 2-post week and want links that help a buyer move, not links that exist to look busy.

SitePilot’s bar matches the core promise: more qualified people engaging with the product every month while they keep building. Reciprocal links are ops hygiene after publish — not a third publish slot, and not a reason to invent relatedness.

When “week two” is enough to start

You do not need a catalog. You need a cluster spine:

SignalReady?
≥3 live posts in one buyer clusterYes
Each post already has ≥1 honest in-body linkYes
You can name problem → method → next-step without stretchingYes
Posts are leftovers from different topicsNo — fix the map first

If the map is mush, stop. Rebuild the one-page cluster map before you weave links. Reciprocal linking cannot rescue orphans that never belonged together.

For the pattern itself (problem → how → product), read Internal links that move buyers. This article is the ops checklist after you already have a small set live.

The reciprocal checklist (run once after week two)

Work live URLs only. Open each post and ask five questions. Write answers in a short table (Monday digest or ops note).

#CheckPass looks likeFail looks like
1Sibling exists?Another live post answers the next question a skimmer would askOnly a keyword overlap (“both mention SEO”)
2Natural sentence?You can insert the link mid-paragraph without rewriting the claimYou need a fake “Related:” dump to justify it
3Direction clear?Link goes problem→method, method→QA, skip ritual→cadence, or any node→product onceBidirectional spam (“every page links every page”)
4Anchor honest?Anchor describes the destination job (“2-post week”, “skip ritual”)Exact-match keyword stuffing
5Cap held?≤2 new reciprocal edits per older post in one passTouching every paragraph to “maximize links”

Reciprocal here means: if post A points to B because B is the next useful step, B may point back to A when A is the clearer problem statement — only when both sentences stay true. It does not mean every pair must cross-link.

Suggested spine for a cadence cluster

Use this as a default map, then delete edges that feel forced:

  1. Promise / outcome post ↔ cadence ops post
  2. Cadence ops ↔ QA gates
  3. QA gates ↔ skip ritual (when empty slots are part of the system — see How to skip a slot without losing the habit)
  4. Internal-linking guide ↔ any method post that tells people to “add a link”
  5. Each strong node → product / waitlist once, in context

That is usually six to ten intentional links across the cluster — not fifty.

When to skip a reciprocal edit

Skip is a feature. Do not add a sibling link when:

  • The older post already has two solid mid-article links and a clear CTA
  • The only connection is shared jargon (“AI”, “content”, “growth”)
  • You would need to invent a transition paragraph to make the link fit
  • The destination is draft-only, killed, or behind a broken path
  • You are “catching up” after a skip week by bulk-editing HTML instead of logging the skip
  • The edit would ship the same calendar week you already hit the 2/week publish cap — link hygiene is allowed; a new article is not required

If the draft for a new title is not ready, keep the queue honest and skip the publish slot. Link passes on existing URLs can still happen; they are not a substitute for a third post.

Anti-spam rules (fail-closed)

Treat these as hard gates — same spirit as publish QA:

  1. No footer farms. A “Related posts” blob with five near-duplicates is worse than one mid-article link.
  2. No identical anchors repeated across the site for the same URL.
  3. No reciprocal loops of three+ (“A→B→C→A”) unless each hop answers a real reader question.
  4. No product spam. Waitlist / pricing / signup appears when intent is high — not in every H2.
  5. No invented proof. Do not claim rankings, “link equity,” or traffic lifts you did not measure.
  6. No silent orphans. If you remove a post, strip inbound links in the same change set.
  7. Prefer skip over force. If the checklist fails, leave the older post alone and note it in the digest.

Cadence without these rules turns a helpful cluster into a maze. Buyers bounce; quality gates should catch density games before they go live.

A 30-minute reciprocal pass (copy this)

MinuteAction
0–5List live URLs in the cluster (title · URL · one-line job)
5–15Mark missing edges on the spine (only where a natural sentence exists)
15–25Edit at most two older posts; one link each unless a second is obvious
25–30Log in Monday digest: URLs touched · links added · links skipped + reason

Example digest line:

2026-09-24 reciprocal pass — added skip ritual → two-post-week; skipped quality-gated→customer-brief (no natural sentence); no new publish (cadence 2/2).

Keep the log boring. Boring is how the habit survives shipping weeks.

What “done” looks like after week two

You are done with the first reciprocal pass when:

  • Every live cluster post has at least one human-meaningful outbound internal link
  • The spine (problem ↔ method ↔ bar ↔ product) is visible without a sitemap tour
  • At least one path reaches the product or waitlist without a hard sell paragraph
  • Skipped edges are written down (so nobody “fixes” them with spam later)
  • You did not publish an extra article just to create more link targets

Further passes belong on a light cadence — for example, after every two new posts — not nightly churn.

Start next week

  1. Export the live cluster list (dogfood or customer).
  2. Run the five-check table once; time-box thirty minutes.
  3. Ship at most a handful of honest sibling links.
  4. Put the next cluster title in the queue — do not force a third post the week you already hit two.
  5. If you want this loop run without becoming the editor, join the SitePilot waitlist — same rules we dogfood: capped cadence, fail-closed QA, links that move buyers.

Reciprocal linking after week two is maintenance, not theater. A few true sibling links beat a decorative web of everything-to-everything.
